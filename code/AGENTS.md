# 游乐场风格用户注册登录系统 - 需求拆解文档

## 产品概述

- **产品类型**: 单页应用（用户注册登录系统 + 欢迎页 + 个人中心）
- **场景类型**: <scene_type>prototype-app</scene_type>
- **目标用户**: 游乐场主题网站的访客与注册用户
- **核心价值**: 提供欢乐童趣的注册登录体验，使用户快速进入游乐场主题氛围
- **界面语言**: 中文
- **主题偏好**: 浅色（游乐场风格，明亮活泼）
- **导航模式**: 路径导航（单页应用内路由切换，无传统导航栏）
- **导航布局**: 无全局导航栏（页面间通过按钮/链接跳转，首页右上角有"我的"图标入口）

---

## 页面结构总览

> **说明**：单页应用（SPA），通过 JavaScript 控制页面切换，共 4 个视图页面

| 页面名称 | 文件名 | 路由 | 页面类型 | 入口来源 |
|---------|-------|------|---------|---------|
| 登录页 | `LoginPage.tsx` | `/login` | 一级 | 默认显示 / 注册页"去登录"链接 / 退出登录 |
| 注册页 | `RegisterPage.tsx` | `/register` | 一级 | 登录页"去注册"链接 |
| 首页 | `HomePage.tsx` | `/` | 一级 | 登录成功后跳转 / 我的页面返回 |
| 我的页面 | `ProfilePage.tsx` | `/profile` | 一级 | 首页右上角"我的"图标 |

> **路由守卫规则**：未登录时访问 `/` 或 `/profile` 自动跳转 `/login`；已登录时访问 `/login` 或 `/register` 自动跳转 `/`

## 页面布局建议

### 登录页 / 注册页
- **布局模式**: 单栏居中卡片式布局，左右两侧有装饰元素
- **视觉重心**: 登录/注册表单卡片（居中突出）
- **结果承载区**: 表单下方的错误提示区 + 成功 toast 反馈；初始态为空状态（无提示）

### 首页
- **布局模式**: 顶部用户栏 + 主内容区（欢迎区 + 游乐项目展示卡片网格）
- **视觉重心**: 欢迎语 + 游乐项目展示区
- **结果承载区**: 游乐项目卡片网格（初始态为 mock 展示数据）

### 我的页面
- **布局模式**: 顶部返回栏 + 用户信息卡片 + 操作区
- **视觉重心**: 用户信息卡片
- **结果承载区**: 编辑表单区（点击修改时展开）；初始态为信息展示态

## 功能列表

### 登录页（LoginPage）
- **页面目标**: 用户输入账号密码完成登录，或跳转到注册页
- **功能点**:
  - **登录表单提交**: 用户名/邮箱 + 密码输入，点击登录按钮后从 localStorage 用户列表中校验，成功则写入 currentUser 并跳转首页，失败显示错误提示
  - **表单验证**: 实时校验用户名/邮箱和密码不能为空，格式错误即时反馈
  - **跳转注册页**: 点击"没有账号？去注册"链接，平滑切换到注册页视图
  - **登录状态检测**: 页面加载时若检测到已登录状态，自动跳转首页

### 注册页（RegisterPage）
- **页面目标**: 用户填写信息完成注册
- **功能点**:
  - **注册表单提交**: 填写用户名、邮箱、密码、确认密码，提交时校验通过后写入 localStorage 用户列表，注册成功后自动登录并跳转首页
  - **表单验证**: 校验所有字段非空、邮箱格式正确、密码与确认密码一致、用户名/邮箱不重复
  - **跳转登录页**: 点击"已有账号？去登录"链接，平滑切换到登录页视图

### 首页（HomePage）
- **页面目标**: 欢迎登录用户，展示游乐场主题内容
- **功能点**:
  - **欢迎信息展示**: 顶部显示当前登录用户的用户名，如"欢迎回来，{username}！🎡"
  - **游乐项目展示**: 以卡片网格形式展示游乐场项目（摩天轮、旋转木马、过山车等），含图标、名称、简短描述
  - **进入我的页面**: 右上角"我的"图标按钮，点击跳转个人中心页面
  - **退出登录**: 点击退出登录按钮，清除 currentUser 并跳转回登录页
  - **登录守卫**: 未登录时自动重定向到登录页

### 我的页面（ProfilePage）
- **页面目标**: 展示和管理用户个人信息
- **功能点**:
  - **用户信息展示**: 卡片形式展示用户名、邮箱、注册时间等信息
  - **修改个人信息**（可选）: 点击编辑按钮展开表单，可修改用户名/邮箱，提交后更新 localStorage 并刷新显示
  - **返回首页**: 点击返回按钮，平滑过渡回首页
  - **退出登录**: 点击退出登录按钮，清除登录状态并跳转登录页
  - **登录守卫**: 未登录时自动重定向到登录页

## 数据共享配置

| 存储键名 | 数据说明 | 使用页面 |
|---------|---------|---------|
| `__app_funpark_users` | 注册用户列表，类型为 `IUser[]` | 登录页、注册页、我的页面 |

```ts
interface IUser {
  /** 用户唯一标识 */
  id: string;
  /** 用户名 */
  username: string;
  /** 邮箱 */
  email: string;
  /** 密码（明文存储，仅 demo 用途） */
  password: string;
  /** 注册时间（ISO 字符串） */
  createdAt: string;
}

interface ICurrentUser {
  id: string;
  username: string;
  email: string;
  createdAt: string;
}
```

# UI 设计指南

## 1. 设计推导依据

- **参考意图**: Free Direction —— 无参考材料，按游乐场主题语义自主设计完整视觉系统
- **核心情绪 / 应用类型**: 欢乐童趣、明亮活泼的用户认证系统，以糖果色与游乐园装饰营造轻松愉悦的登录注册体验
- **独特记忆点**: 糖果色渐变卡片 + 浮动气球与云朵装饰 + 圆润泡泡按钮，每个页面都像一张游乐园入场券

## 2. Art Direction

- **方向名**: 糖果游乐园
- **Design Style**: Soft Pop 柔彩流行 + Rounded 圆润几何 —— 以糖果色渐变、圆润饱满的形态和轻盈浮动的装饰，准确传达游乐场的欢乐与童趣
- **DNA 参数**: 圆角极大（pill/2xl+）/ 阴影柔层叠 / 间距宽松 / 字体圆润可爱 / 装饰手法为气球、云朵、彩旗、彩虹等扁平卡通元素漂浮点缀
- **应用类型**: Tool —— 表单与认证流为核心，内容居中布局，装饰环绕服务信息

## 3. Color System

**色彩关系**: 彩虹糖果色系，以粉紫渐变为主视觉锚点，搭配天蓝、鹅黄、橙粉为辅助装饰色，米白云朵底为中性基底，整体高饱和但低明度压力
**配色设计理由**: primary 粉紫渐变承载品牌识别与主行动 CTA，呼应游乐园的梦幻氛围；bg 采用柔粉到天蓝的渐变营造天空感；card 奶白底保证表单清晰可读；accent 鹅黄与粉橙用于 hover、装饰与次级交互
**主色推导**: 从游乐园摩天轮与棉花糖的色彩语义出发，选择粉紫渐变作为 primary 主色，象征梦幻与欢乐；辅助色从彩虹色带中抽取天蓝、鹅黄、橙粉，形成统一的糖果色家族
**使用比例**: 50% 中性基底 / 35% 糖果辅助色 / 15% primary 粉紫；primary 仅用于主按钮、品牌标识、关键状态，不滥用填充

| 角色 | CSS 变量 | Tailwind Class | HSL 值 | 设计说明 |
|---|---|---|---|---|
| bg | `--background` | `bg-background` | hsl(320 100% 97%) | 页面背景，粉→天蓝渐变底，云朵装饰叠加 |
| card | `--card` | `bg-card` | hsl(0 0% 100%) | 卡片、表单承载面，奶白略带粉调，半透明毛玻璃感 |
| text | `--foreground` | `text-foreground` | hsl(280 40% 25%) | 标题和正文，深紫棕色，温柔不刺眼 |
| textMuted | `--muted-foreground` | `text-muted-foreground` | hsl(280 20% 55%) | 占位符、说明、辅助文字 |
| primary | `--primary` | `bg-primary` / `text-primary` | hsl(330 100% 65%) | 主交互、CTA、品牌识别，粉紫渐变起始色 |
| primaryForeground | `--primary-foreground` | `text-primary-foreground` | hsl(0 0% 100%) | primary 上的文字和图标 |
| accent | `--accent` | `bg-accent` | hsl(48 100% 85%) | hover/focus 浅底、选中浅底、装饰点缀，鹅黄 |
| accentForeground | `--accent-foreground` | `text-accent-foreground` | hsl(30 80% 35%) | accent 上的文字和图标 |
| border | `--border` | `border-border` | hsl(320 50% 88%) | 输入框、卡片边界，浅粉柔边 |

**语义色提示**:
- 成功：hsl(140 70% 55%) / bg: hsl(140 80% 95%) / border: hsl(140 60% 75%) / text: hsl(140 60% 30%)，糖果绿，与主色同饱和度
- 警告：hsl(42 100% 60%) / bg: hsl(48 100% 92%) / border: hsl(42 90% 75%) / text: hsl(30 80% 35%)，糖果橙黄，与 accent 同源
- 错误：hsl(0 90% 65%) / bg: hsl(0 100% 95%) / border: hsl(0 80% 80%) / text: hsl(0 70% 35%)，草莓红，饱和度与 primary 对齐

## 4. 字体与节奏

- **font-display**: ZCOOL KuaiLe —— 圆润卡通字体，大标题和品牌字用，强化游乐场童趣氛围
- **font-body**: Noto Sans SC —— 正文表单清晰易读，圆润笔画与 display 风格协调
- **字号**: H1 text-4xl ~ text-5xl；H2 text-2xl ~ text-3xl；body text-base；muted text-sm
- **圆角**: 极端大 —— 按钮 pill 形 `rounded-full`，卡片 `rounded-3xl`，输入框 `rounded-2xl`，全面呼应糖果与气球的圆润感

## 5. 全局布局契约

- **Reference Layout Use**: 按需求结构推导，4 个页面均为居中卡片式布局
- **Page / Section Order**: 登录页 → 注册页 → 首页 → 我的页面，与路由表 1:1 对齐
- **Standard Content Zone**: max-w-md ~ max-w-lg + `mx-auto`，认证表单居中；首页内容区 max-w-4xl
- **Shell / Frame Alignment**: 无固定 chrome，所有页面内容容器独立居中，装饰元素全宽浮动
- **Padding & Rhythm**: `px-6 py-12 md:py-16`，卡片内边距 `p-8 md:p-10`，保持 8px 倍数节奏
- **Full-bleed Zones**: 页面背景渐变、装饰云朵/气球/彩旗 `w-full` 铺满视口，内容卡片受 Standard Content Zone 约束
- **Local Narrowing**: 登录/注册表单在卡片内 `max-w-sm mx-auto`，保证表单聚焦
- **Overflow Strategy**: 移动端装饰元素超出视口部分 `overflow-hidden`，不出现横向滚动
- **Flexibility Boundary**: 允许移动端 padding、卡片间距和装饰元素数量微调；不允许切换圆角级别、主色和字体风格

## 6. 视觉与动效

- **装饰**: 气球簇、棉花云朵、彩旗串、彩虹弧线、摩天轮剪影，扁平卡通风，漂浮于页面四角与背景
- **阴影/边界**: 柔层叠 —— 卡片用双层软阴影 `shadow-lg + 内发光`，按钮带轻微阴影与 hover 上浮
- **动效**: 丰富 —— 页面切换用淡入 + 轻微上浮（300ms ease-out）；按钮 hover 放大 1.03 倍 + 阴影加深 + 上移 2px；装饰元素持续缓慢浮动（3s-5s 正弦循环）；表单聚焦时输入框轻微发光

## 7. 组件原则

- 按钮、输入框、链接必须有 Default / Hover / Active / Focus / Disabled 五种状态
- Primary 按钮为粉紫渐变 + pill 形 + 软阴影，hover 上浮发光；Secondary 用白底粉边 + 文字色
- 输入框为大白底 + 柔粉边 + 大圆角 + 内阴影，focus 时粉紫光晕扩散
- 卡片为半透明白底 + 毛玻璃 backdrop-blur + 大圆角 + 双层软阴影，漂浮感
- 错误提示为草莓红文字 + 浅红底圆角标签，配合轻微抖动动画
- 加载与空状态延续糖果卡通风，用游乐元素插画替代默认 loading 图标

## 8. Image Direction

- **Image Role**: 背景装饰图 + 页面插画元素，服务于游乐场氛围营造，不抢信息层级
- **Image Art Direction**: 扁平卡通风，柔和描边，马卡龙配色，简洁几何造型。背景图为天空渐变 + 云朵 + 远处摩天轮剪影，低透明度作氛围层；装饰元素为气球簇、彩旗串、彩虹、旋转木马顶部，独立漂浮分布。光线均匀明亮，无强烈阴影，整体像儿童绘本插图质感
- **Image Prompt Keywords**: 扁平卡通游乐园, 马卡龙糖果色, 气球云朵摩天轮, 彩虹彩旗旋转木马, 柔和圆润造型, 儿童绘本风格, 明亮日光, 简洁几何, 低饱和度粉紫蓝黄, 漂浮装饰元素, 无文字插画
- **Image Avoidance**: 避免写实照片、3D 渲染、暗黑风格、复杂细节、真人形象、商业素材图库感、高对比刺眼配色、杂乱堆砌

## 9. Anti-patterns

- **Split personality**: 登录页用糖果风、首页突然变简洁 SaaS 风；四页共享同一色彩、圆角、装饰、字体系统
- **Decoration overload**: 装饰元素铺满整个页面遮住表单内容；装饰只在四角与背景低密度分布，信息区保持干净
- **Default form drift**: 表单回到默认直角灰边输入框；所有输入控件必须使用大圆角 + 柔边 + 聚焦光晕
- **Invisible interaction**: 只做 hover 动画忽略 focus-visible；键盘聚焦必须有清晰的粉紫光晕环
- **Rainbow chaos**: 每个元素一种颜色造成视觉混乱；按 50-35-15 比例分配基底/辅助/主色，同页面装饰色不超过 3 种
- **Status color clash**: 成功警告错误色用高饱和实色盖过主色；语义色饱和度与 primary 对齐，用浅底+柔边呈现
